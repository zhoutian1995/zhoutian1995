# 周维天（小天）· 杭州的 FDE

**杭州纬聆科技创始人。FDE（Forward Deployed Engineer，前置部署工程师）：帮企业把 AI 接进真实业务流程，直到结果能被验收。**

- **合作方式**：按约定结果付费；支持先试用——先在一个小场景试岗，满意再扩编，不满意随时停。
- **交付形式**：AI 员工代运营（Agent + 人工审核），配套企业 AI 诊断与内训；不卖系统，不按账号或调用次数收费。
- **不限定行业**：只看一件事——有没有量大、重复、规则说得清的工作一直缺人做。
- **背景**：程序员出身，现在 all in AI，日常用 Claude Code / Codex 多 Agent 写代码、跑交付；创始人本人对接，对结果负责。
